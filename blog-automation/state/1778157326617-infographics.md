```
Notionゲスト招待の3つの主要ユースケースについてのインフォグラフィックを作成してください。

【セクション内容】
Notionのゲスト招待機能を使うと、社外メンバーに特定ページだけを共有でき、営業支援やクライアント連携などで大幅な業務効率化が実現できます。具体的には以下の3つのシーンで特に活躍します。

【3つのユースケース】

3. 外部スタッフ・フリーランサーへの業務情報共有：必要なページだけを外部メンバーに公開でき、情報セキュリティを保ちながら業務効率化を実現できます。

【作成指示】
- タイトル案：「Notionゲスト招待が活躍する3つのシーン」
- ポイント：各ケースのビジネスシーン、具体的なメリット、工数削減効果
- レイアウト種別：横並び比較表（3列で各ケースを並べて表現）
- 補足：ビジネス向けで統一感のある配色、各シーンを表すアイコンやイラストを活用してください
```

## セクション2: ゲストを招待する5ステップ｜具体的な操作手順

```
Notionゲスト招待の5ステップフロー図のインフォグラフィックを作成してください。

【セクション要約】
Notionでゲストを招待する5つの連続ステップ：
1. ワークスペース設定を開く（左下のワークスペース名 → 設定 → メンバー → ゲストタブ）
2. ゲストメンバーを追加する（共有したいページの「共有」ボタン）
3. メールアドレスを入力して招待（相手のメールアドレスを正確に入力）
4. 権限レベルを設定する（相手の役割に応じた操作範囲を選択）
5. 招待を送信して確認（招待メール送信、ゲスト追加完了）

【指示】
タイトル案：「Notionゲスト招待の5ステップフロー」

レイアウト：フロー図（上から下へ、矢印で繋ぐ縦方向フロー）

各ステップのポイント：
- ステップ番号と簡潔なタイトル、1行説明を含める
- 矢印で次のステップへの流れを表現
- 初回チェック（「ゲストを招待できません」表示時の注意）をステップ1に付記
- 補足：「複雑に見えますが、操作はたったの5ステップで完了」というメッセージを頭部に記載
```

## セクション3: 権限設定で迷わない｜セキュリティと利便性の両立ガイド

```
Notion権限レベルの違いを整理した横並び比較インフォグラフィックを作成してください。

**内容の整理:**
Notionゲスト招待時に設定できる3段階の権限（ビューアー・コメンター・エディター）について、それぞれの機能範囲とセキュリティレベルを視覚化。

**作成指示:**

■ タイトル案：「Notion権限設定の3段階｜できること・できないことで選ぶ」

■ 掲載内容（3つの権限を並べる）
1. **ビューアー** 
   - できること：ページ閲覧のみ
   - できないこと：編集・コメント・削除
   - 活用場面：機密文書・参考資料の共有

2. **コメンター**
   - できること：閲覧＋コメント投稿
   - できないこと：編集・削除
   - 活用場面：フィードバック・レビュー

3. **エディター**
   - できること：閲覧・コメント・編集・削除すべて
   - できないこと：ワークスペース設定変更
   - 活用場面：共同編集・チーム内協力

■ レイアウト種別：横並び比較表

■ 補足：セキュリティレベルを色分け（ビューアー＝最も安全、エディター＝最も自由）し、「誰に・何を・どこまで渡すか」が直感的に判断できるよう構成
```

- レイアウト：横軸に時間経過を配置し、各段階の所要時間・具体的タスク・実施内容を視覚化
- 補足：実務的に実行可能な形で、忙しいチーム向けにシンプルかつ継続性の高いスケジュール管理体系であることを強調してください

## セクション5: 実際の運用で起こりやすい問題と解決策

```
Notionゲスト招待トラブルの実運用別対応ガイドのインフォグラフィックを作成してください。

【セクション内容の整理】
Notionのゲスト共有トラブルは「権限エラー」と「アクセス制限」の2種類に分類されます。実運用で頻出する問題と原因・対策は以下の通りです：

**トラブル1：親ページの権限が子ページに引き継がれない**
- 原因：ページ移動やリンク貼り付け後、権限が自動反映されない
- 対策：各ページの共有設定を個別に確認・調整する

**トラブル2：招待メールのリンク有効期限切れ**
- 原因：迷惑メールフォルダへの迷い込み、確認の遅延によりリンク失効
- 対策：管理者による再招待が必須（ゲスト側での対応は不可）

**ゲスト側の予防策**
- 送信元を事前に信頼できる相手として登録
- メール受け取り後、速やかにリンクを開く

【作成指示】
・レイアウト：縦型ポイントリスト
・タイトル案：「Notionゲスト招待 実運用トラブル対応ガイド」
・各問題ごとに「原因」「対策」を視覚的に区別する
・実例：広告代理店ディレクター招待3日後のリンク失効ケースを補足として記載
・カラー：エラー箇所は赤系、解決策は緑系など視認性を確保
```

## セクション6: よくある質問：Notionゲスト招待のトラブル対応

```
Notionゲスト招待の運用トラブル対応Q&Aのインフォグラフィックを作成してください。

【セクション内容の整理】
実際の運用でよく寄せられる疑問4点から、実務的なチェックポイントをまとめます：

1. **権限の後変更は可能**
   - 「共有」ボタン → 権限表示をクリック → ドロップダウンで変更
   - 「閲覧のみ」「コメント可」「編集可」に柔軟に調整可能
   - 変更完了は約30秒

2. **ゲストのアクセス範囲は限定的**
   - 明示的に共有されたページと子ページのみ表示
   - ワークスペース全体は非公開
   - 本文中のリンク先はゲストには開けない

3. **招待通知は自動メール配信**
   - ゲストのメールに招待メール自動送付
   - メール内に直接リンク・アカウント作成案内を記載
   - 迷惑メール確認が必要な場合あり

4. **共有前の安全確認が重要**
   - ページを一度見直す
   - 意図しないリンクが含まれていないか確認

【作成指示】
- インフォグラフィック種別：縦型ポイントリスト
- タイトル案：「Notionゲスト招待＆運用チェックリスト」
- 各ポイントにステップ番号・簡潔なアイコン・実施内容を表記
- 初心者向けに分かりやすく、実務的で迷ったときの辞書として機能する形式で
- 補足：セクションの「運用中に迷ったときの辞書」というコンセプトを視覚的に表現
```
